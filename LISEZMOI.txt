Drone Service CI - site prêt pour Vercel

Avis clients (stockage Neon) :
1. Dans Vercel > Storage, crée une base Neon gratuite et associe-la au projet.
   L'intégration fournit DATABASE_URL à la fonction serverless.
2. Dans le SQL Editor Neon, exécute le fichier neon/reviews.sql.
3. Redéploie le projet Vercel. Les avis envoyés avec l'autorisation de publication
   apparaissent immédiatement sur le site.

Déploiement manuel :
1. Installe Node.js (nodejs.org) si ce n'est pas déjà fait.
2. Ouvre un terminal dans ce dossier et lance : npx vercel --prod
3. Connecte-toi à Vercel si demandé. Choisis le framework "Other", sans commande de build.
   La fonction api/reviews.js est automatiquement déployée avec le site.
   Configure DATABASE_URL dans l'environnement Vercel si Neon n'est pas connecté.

Option GitHub :
1. Connecte le dépôt GitHub à Vercel (Framework "Other", sans commande de build).
2. Chaque mise à jour poussée sur main déclenche un déploiement.
3. Vérifie que DATABASE_URL est configurée dans Vercel.
